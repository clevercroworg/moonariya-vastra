HOW TO USE
1. Generate each image at the size shown, or larger with the same shape (aspect ratio).
2. Save it as JPG (quality ~85, sRGB) using EXACTLY the file name shown.
3. Put it in the folder shown, inside the project. It replaces the placeholder
   that is already there, and the website picks it up automatically (no code change).
4. Keep each file under ~600 KB. Next.js resizes and compresses them for visitors.
5. Every image must fill the frame edge to edge: no borders, drawn frames or white areas.

Real product photos you already sent are used in "New Arrivals" (public/images/products/).
They do not need to be generated.

ADD THIS STYLE LINE TO THE END OF EVERY PROMPT
"Photorealistic luxury fashion editorial, warm golden light, rich jewel tones with
deep maroon and antique gold, crisp detail on the saree weave and zari, natural
skin texture, elegant and graceful, no text, no logo, no watermark."

"text, letters, logo, watermark, distorted hands, extra fingers, western dress,
lehenga, plastic-looking fabric, oversaturated, cartoon, blurry saree border"
